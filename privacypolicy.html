SENTER & SOS

Kebijakan Privasi

Terakhir diperbarui: 24 September 2026

Aplikasi "Senter & SOS" ("kami", "aplikasi ini") dikembangkan oleh Anseb Studio. Kebijakan privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi saat kamu menggunakan aplikasi ini.

1 Informasi yang Kami Kumpulkan

Aplikasi ini sendiri tidak mengumpulkan, menyimpan, atau mengirimkan data pribadi pengguna ke server kami. Aplikasi ini bekerja secara lokal di perangkat kamu.

Namun, aplikasi ini menggunakan layanan pihak ketiga (Google AdMob) untuk menampilkan iklan, yang dapat mengumpulkan data berikut secara otomatis:

  • Advertising ID
  • Informasi perangkat (model, sistem operasi, operator seluler)
  • Alamat IP
  • Data interaksi dengan iklan (klik, tayangan)

2 Izin Perangkat (Permissions)

Aplikasi ini meminta izin berikut:

  • Kamera (Camera): digunakan hanya untuk mengakses lampu LED flash perangkat sebagai fungsi senter. Aplikasi ini tidak mengambil foto, video, atau menyimpan data apa pun dari kamera.
  • Akses Internet & Status Jaringan: digunakan untuk memuat iklan dari Google AdMob.

3 Layanan Pihak Ketiga — Google AdMob

Aplikasi ini menggunakan Google AdMob untuk menampilkan iklan (banner dan rewarded ads). Google AdMob dapat mengumpulkan dan memproses data sesuai dengan kebijakan privasi mereka sendiri. Untuk informasi lebih lanjut, silakan baca:

  • Kebijakan Privasi Google: policies.google.com/privacy
  • Cara Google menggunakan data dari aplikasi yang menggunakan layanan mereka: policies.google.com/technologies/partner-sites

Kamu dapat mengatur preferensi iklan personalisasi melalui pengaturan akun Google kamu di: adssettings.google.com

4 Anak-anak

Aplikasi ini tidak secara khusus ditujukan untuk anak-anak di bawah usia 13 tahun, dan kami tidak dengan sengaja mengumpulkan data pribadi dari anak-anak.

5 Keamanan Data

Karena aplikasi ini tidak menyimpan data pribadi pengguna di server kami, risiko kebocoran data dari sisi kami sangat minim. Data yang diproses oleh AdMob dilindungi sesuai standar keamanan Google.

6 Perubahan Kebijakan Privasi

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Perubahan akan diumumkan melalui pembaruan halaman ini.
